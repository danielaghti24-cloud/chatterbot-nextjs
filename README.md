# Chatbot con Next.js y Google Gemini

Chatbot con parámetros ajustables en tiempo real: system prompt, temperatura, tokens máximos, Top-P y Top-K.

## Instalación
1. `npm install`
2. Crea un archivo `.env.local` con: `GEMINI_API_KEY=tu_clave`
3. `npm run dev` y abre http://localhost:3000

## Tecnologías
Next.js, TypeScript, Tailwind CSS, SDK `@google/genai`.
